
# AI Music Generator 🎵

AI Music Generator is a Python-based music generation application developed using Streamlit and NumPy.

## Features

- Generate instrumental music.
- Multiple music moods.
- Different music styles.
- Adjustable BPM and duration.
- Optional drums and bass.
- Play generated music.
- Download music in WAV format.
- Music generation history.
- Delete saved history.

## Technologies Used

- Python
- Streamlit
- NumPy
- SQLite

## Installation

1. Clone this repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py
